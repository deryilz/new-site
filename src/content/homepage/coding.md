Outside of bug hunting, I also like to code projects in various languages. A few examples:

- [ezRetime](https://github.com/deryilz/ezretime) is a Chrome extension made for speedrun moderators to retime runs uploaded to YouTube, Twitch, or other websites by measuring/calculating the FPS of a video. It supports multiple splits and has convenience features like frame-by-frame navigation and turbo mode. (But sadly, it doesn't support ultra turbo mode yet.)
- [The Dublin Shelf Finder](https://shelf-finder.com/) is software that allows librarians to create virtual maps of the shelves in their library, while a corresponding Chrome extension adds an interactive version of this map to Destiny Discover (library software), showing people how to find the books they're looking for.
- [rev-finder](https://github.com/deryilz/rev-finder) is a multithreaded C++ tool that searches for Minecraft: Bedrock Edition seeds with interesting properties. It makes use of modular arithmetic tricks like Lagrange-Gauss reduction in order to be pretty fast.
- [hexagon-regex-solver](https://github.com/deryilz/hexagon-regex-solver) is one of my many mini projects involving Z3 (an equation solver). It parses and translates [regular expressions](https://en.wikipedia.org/wiki/Regular_expression) into `And`/`Or`/`Not` constraints over a hexagon grid to find the only solution to [this puzzle from MIT's 2013 Mystery Puzzle Hunt](https://gregable.com/p/regexp-puzzle.html) in just a few seconds. The code can be easily adapted from a hexagon to a rectangle or cube or whatever you like.
